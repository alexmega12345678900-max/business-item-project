# 설문 초안 (선택)

> 상태: 보류 (2026-10-15 결정, 지금은 배포하지 않음)
> 목적: 자료 조사 수치를 우리 주변 사람들의 실제 경험으로 보강
> 대상: 20~30대 지인 20~30명 · 도구: 구글폼 · 기간: 2~3일 · 소요 시간: 1분

## 문항

1. 현재 유료로 구독 중인 서비스는 몇 개인가요?
   - 0개 / 1~2개 / 3~4개 / 5개 이상
2. 지금 구독 중인 서비스의 다음 결제일을 모두 알고 있나요?
   - 모두 안다 / 일부만 안다 / 거의 모른다
3. 최근 1년 안에 무료체험을 해지하지 못해 결제된 적이 있나요?
   - 있다 / 없다 / 무료체험을 써 본 적 없다
4. 최근 1년 안에 온라인 쇼핑 반품·환불 기한을 놓친 적이 있나요?
   - 있다 / 없다
5. 전자제품 보증기간이 언제까지인지 알고 있나요?
   - 대부분 안다 / 일부만 안다 / 거의 모른다
6. 기한을 놓쳐서 손해 본 금액은 1년에 대략 얼마인가요?
   - 없음 / 1만 원 미만 / 1~5만 원 / 5~10만 원 / 10만 원 이상
7. 결제 문자를 붙여 넣으면 기한을 대신 기억하고 알려 주는 서비스가 있다면 쓰겠나요?
   - 꼭 쓰겠다 / 써 보겠다 / 잘 모르겠다 / 안 쓰겠다
8. 위 서비스에 월 얼마까지 낼 의향이 있나요?
   - 무료만 쓰겠다 / 1,000원 / 2,000원 / 3,000원 / 5,000원 이상
9. (선택) 기한을 놓쳐서 손해 본 경험이 있다면 짧게 적어 주세요.

## 발표에 쓰는 방법

- 3·4번 → "우리 주변 N명 중 X%도 기한을 놓친 적이 있다" (문제 정의 슬라이드)
- 7번 → 사용 의향 (해결책 슬라이드)
- 8번 → 프리미엄 가격(월 1,900원) 근거 (수익 모델 슬라이드)
- 9번 → 실제 사례 인용 (대상 고객 슬라이드)
