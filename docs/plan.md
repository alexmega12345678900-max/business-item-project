# 기획서: 놓침제로 (가칭)

> 팀: 1조 · 상태: 발표 준비 1차 완료 · 마지막 갱신: 2026-10-18
> 이 문서가 모든 내용의 기준입니다. 발표 슬라이드는 이 문서를 요약해서 만듭니다.
> 근거 수치와 출처: [docs/research/01-시장-문제-근거.md](research/01-시장-문제-근거.md) · 사업성 계산: [docs/research/02-사업성-계산.md](research/02-사업성-계산.md)

## 0. 발표 목표

**흩어진 기한 문제에 하나로 통일된 해결 방식을 제시하고, 그것이 사업 아이템으로서 가치가 있음을 증명한다.**

발표는 10분 내외, 기승전결 구조로 본발표 8장 + 부록(출처) 1장입니다. 이 문서는 상세 근거를 모두 담고, 슬라이드는 핵심만 보여 줍니다.

| 단계 | 말할 것 | 슬라이드 |
|---|---|---|
| 기 · 문제 | 결제 후 기한을 놓쳐 피해가 늘고, 돌려받기는 어렵다 (2.7배, 41.7%, 58.4%) | 2 |
| 승 · 원인 | 기억은 사람 몫이고, 기존 앱은 이미 나간 돈만 본다 | 3 |
| 전 · 해결 | 기한 = 기준일 + 규칙, 붙여넣기 한 번으로 네 가지 기한 모두 | 4–5 |
| 결 · 가치 | 유효 시장 841만 명, 연 매출 6,840만 원, 운영비는 매출의 5% | 6–8 |

## 1. 한 줄 소개

**결제 문자 하나만 붙여 넣으면, 무료체험·구독·반품·보증기간의 기한을 대신 기억하고 마감 전에 알려 주는 웹앱**

> "샀으면 끝이 아니다. 놓치면 손해인 기한을 대신 챙겨 드립니다."

## 2. 문제 정의

결제나 구매 한 번에 신경 써야 할 기한이 여러 개 따라옵니다. 지금은 이 기한들이 각 앱, 쇼핑몰, 영수증에 흩어져 있어 사람이 직접 기억해야 합니다.

| 기한 | 놓치면 |
|---|---|
| 무료체험 종료 | 원하지 않는 유료 결제 |
| 구독 갱신일 | 안 쓰는 서비스에 계속 돈이 나감 |
| 반품·환불 기한 (수령 후 7일) | 마음에 안 드는 물건을 떠안음 |
| 보증기간 만료 | 무상 수리를 유상으로 고침 |

**근거**
- 무료체험 자동결제 피해구제 신청 2022년 26건 → 2024년 71건, **2년 만에 약 2.7배** (한국소비자원)
- 피해를 입어도 **전액 보상받은 경우는 41.7%**, 31.1%는 한 푼도 돌려받지 못함 (한국소비자원) — 사후 구제보다 사전 예방이 필요
- 구독 이용자 **58.4%가 해지에 어려움** (서울시전자상거래센터, 20~50대 2,000명)
- 구독 이용자 56%가 무료체험 후 유료전환 등 다크패턴 경험, 49%는 사전 안내가 부족했다고 응답

## 3. 대상 고객

**주 고객: 온라인 쇼핑과 구독 서비스를 많이 쓰는 20~30대**
- 20~30대가 가장 다양한 카테고리를 유료 구독 (오픈서베이 2025)
- 구독 서비스 월평균 지출 40,530원 (서울시 조사)

**대표 사용자 예시**
> 27세 직장인 민지. OTT 3개, 쇼핑 멤버십 1개, AI 서비스 1개를 구독 중. 지난달 영상 편집 앱 7일 무료체험을 잊어 연간 결제 8만 원이 빠져나갔고, 온라인으로 산 운동화는 반품 기한을 하루 넘겨 반품하지 못했다.

**지금 고객이 문제를 해결하는 방법**
- 그냥 기억한다 → 자주 놓침
- 캘린더나 메모에 직접 적는다 → 매번 적어야 해서 꾸준히 못 함
- 카드사·금융 앱으로 결제 내역 확인 → 이미 돈이 나간 뒤에야 알게 됨

## 4. 시장·경쟁 조사

**시장**
- 한국 구독 이용자 1인당 평균 3.4개 구독, 연간 약 48만 원 지출 (Bango 2024)
- **한국 소비자 71%가 구독 통합 관리를 원함** — 일본 56%, 대만 66%보다 높음 (Bango 2024)
- 서울시민 95.9%가 구독 서비스 1개 이상 이용

**경쟁 서비스**

| 경쟁 서비스 | 하는 일 | 한계 | 우리와의 차이 |
|---|---|---|---|
| 구독 관리 앱 (Pandora, SubsHub, 마이구들) | 구독 목록, 결제일 알림 | 직접 입력, 구독만 다룸, 앱 설치 필요 | 문자 붙여넣기로 자동 등록, 4가지 기한 통합, 설치 없는 웹앱 |
| 금융 앱 (토스, 핀크, 카드사) | 정기결제 내역 조회 | 이미 결제된 것만 보임, 계좌 연동 필요 | 결제 **전** 기한(무료체험)과 결제 **후** 기한(반품·보증)까지, 계좌 연동 없음 |
| Rocket Money (미국) | 계좌 연동 자동 탐지, 해지 대행 | 국내 미지원, 무료체험 수동 입력 | 국내 결제 문자 형식에 맞춤 |
| 캘린더·메모 | 직접 기록 | 기억해서 적어야 함 | 기한을 자동 계산 |

**우리만 하는 것:** 기존 서비스는 **이미 나가는 돈**만 보여 줍니다. 놓침제로는 **돈이 나가기 전의 기한**을 챙깁니다.

## 5. 해결책

**서비스가 하는 일**
1. 사용자가 결제 문자, 주문 확인 메일, 영수증 사진 중 하나를 올린다.
2. AI가 상품명, 결제일, 금액, 기한 종류를 읽어 내 기한을 자동 계산한다.
3. "다가오는 기한" 목록에 정리하고, 마감 3일 전·1일 전에 알림을 보낸다.
4. 알림에서 바로 해지·반품 방법 안내로 이어진다.

**하나의 공식으로 모든 기한을 처리한다**

네 가지 기한은 겉보기엔 다르지만 원인이 같습니다. 결제하는 순간 기한이 생기는데, 그것을 기억하는 일은 사람에게 맡겨져 있습니다. 그래서 해결도 하나의 공식으로 통일합니다.

> **기한 = 기준일 + 규칙**

| 기한 | 기준일 (문자·메일에서 읽음) | 규칙 |
|---|---|---|
| 무료체험 종료 | 가입일 | + 체험 기간 (예: 7일) |
| 구독 갱신 | 결제일 | + 결제 주기 (월·연) |
| 반품 기한 | 수령일 | + 7일 (전자상거래법 청약철회 기간) |
| 보증기간 | 구매일 | + 보증 기간 (보통 1년) |

기한 종류가 늘어나도 규칙 한 줄만 추가하면 됩니다. 입력, 목록, 알림은 모두 같은 방식으로 처리합니다.

**왜 기존 방법보다 나은가**
- **등록이 쉽다:** 직접 입력 대신 붙여넣기 한 번
- **한곳에서 본다:** 4가지 기한을 한 목록에
- **미리 막는다:** 결제 후 확인이 아니라 결제 전 알림
- **부담이 적다:** 계좌·카드 연동 없음, 앱 설치 없음

## 6. 핵심 기능

1. **붙여넣기 등록:** 결제 문자·메일 내용을 붙여 넣으면 AI가 기한을 추출
2. **다가오는 기한 목록:** 마감 순서로 정렬, 남은 일수(D-day) 표시
3. **마감 전 알림:** 웹 푸시 또는 이메일, 3일 전·1일 전
4. **해지·반품 안내:** 서비스별 해지 경로와 반품 기한 규정 안내

## 7. 수익 모델

| 방식 | 내용 | 시기 |
|---|---|---|
| **부분 유료 (주 수익)** | 기본 등록·알림 무료. 프리미엄 월 1,900원: 영수증 사진 인식, 무제한 등록, 연간 절약 리포트, 가족 공유 | 2단계부터 |
| 제휴 추천 | 해지한 서비스보다 저렴한 대안·결합 상품 추천 수수료 | 3단계 |

가격 근거: 경쟁 구독 관리 앱과 해외 서비스(월 $6~14)보다 낮게 책정해 진입 장벽을 낮춤. 지불 의향 설문은 보류(docs/survey.md 초안만 준비).

## 8. 사업성

계산 근거와 가정: [docs/research/02-사업성-계산.md](research/02-사업성-계산.md)

**시장 규모**

| 구분 | 정의 | 규모 |
|---|---|---|
| 전체 시장 | 구독 서비스를 쓰는 20~30대 | 약 1,185만 명 · 연 2,700억 원 |
| 유효 시장 | 그중 통합 관리를 원하는 사람 (71%) | 약 841만 명 · 연 1,920억 원 |
| 목표 시장 | 3년 안에 확보할 가입자 (유효 시장의 약 1.2%) | 10만 명 |

**매출 (가입자 10만 명, 유료 전환율 3% 기준)**
- 유료 사용자 3,000명 × 연 22,800원 = **연 6,840만 원**
- 보수(2%) 4,560만 원 · 낙관(5%) 1억 1,400만 원
- 전환율 근거: 일반 소비자용 부분 유료 앱 2~5%, RevenueCat 2026 중앙값 2.1%

**비용**
- 사용자 1명의 월 AI 비용 약 1원, 서버 요금제 월 약 7,000원
- 10만 명 기준 총 운영비 연 약 340만 원 (결제 수수료 포함) → **매출의 약 5%**
- **유료 사용자 4명이면 월 서버비 회수**
- 인건비·마케팅비 제외 (팀이 직접 만들고 운영)

**사용자에게도 이득**
- 구독 하나당 월 약 5,200원 (OTT 유료 이용자 월 10,909원, 평균 2.1개)
- 안 쓰는 구독 하나만 제때 해지해도 프리미엄 요금(월 1,900원)의 약 2.7배를 아낌

## 9. 실행 계획

모두 팀(과 AI 도구)이 직접 만들 수 있는 범위로 계획합니다. 금융 계좌 연동, 앱스토어 출시처럼 별도 인가·심사가 필요한 것은 제외합니다.

| 단계 | 내용 | 시기 |
|---|---|---|
| 1단계: 최소 기능 제품 | 웹앱 — 문자 붙여넣기 등록, 기한 목록, 알림 (무료체험·구독 중심) | 출시 후 1~2개월 |
| 2단계: 기한 확장 | 영수증 사진 인식, 반품·보증기간 자동 계산, 프리미엄 요금제 | 3~4개월 |
| 3단계: 등록 자동화 | 브라우저 확장 — 결제·무료체험 가입 순간 감지해 등록 제안 | 5~6개월 |

**기술 구성 (전부 Cloudflare 안에서)**
- 웹앱: 휴대폰 홈 화면에 설치 가능한 PWA, Cloudflare Pages
- 서버: Cloudflare Workers
- 기한 추출: Workers AI
- 데이터: Cloudflare D1
- 알림: 매일 예약 실행 → 웹 푸시·이메일
- 장점: 초기 비용이 거의 없고, 사용자가 늘면 그만큼만 비용 증가

## 10. 기대 효과

- **사용자:** 원치 않는 결제와 놓친 환불을 줄여 연간 지출 절약 (구독 연 48만 원 중 일부)
- **사회:** 다크패턴 규제(2025년 2월 시행)만으로 막기 어려운 피해를 소비자 쪽에서 예방
- **사업:** 한국 소비자의 높은 통합 관리 수요(71%)를 겨냥하고, 운영비가 매출의 약 5%인 서비스
