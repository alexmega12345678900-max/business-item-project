02 해결 · 하나의 공식

네 가지 문제, 원인은 하나

결제하는 순간 기한이 생기는데, 기억하는 일은 사람 몫입니다. 그래서 해결도 하나로 통일합니다.

기한 = 기준일 + 규칙

기한기준일 (문자·메일에서 읽음)규칙
무료체험 종료가입일+ 체험 기간 (예: 7일)
구독 갱신결제일+ 결제 주기 (월·연)
반품 기한수령일+ 7일 (전자상거래법 청약철회)
보증기간구매일+ 보증 기간 (보통 1년)

기한 종류가 늘어도 규칙 한 줄만 추가하면 됩니다. 입력·목록·알림은 모두 같은 방식.

02 해결 · 사용 흐름

붙여 넣으면, 기억은 저희가

기한 종류가 달라도 사용자가 하는 일은 같습니다. 붙여 넣기 한 번.

  1. 붙여넣기결제 문자, 주문 메일, 영수증 사진
  2. AI가 읽기상품명, 결제일, 기한 종류 추출

04 실행 계획

우리가 직접 만들 수 있는 것부터

  1. 1단계 · 1~2개월웹앱 출시 — 문자 붙여넣기, 기한 목록, 알림 (무료체험·구독)
  2. 2단계 · 3~4개월영수증 사진 인식, 반품·보증기간 자동 계산, 프리미엄 요금제
  3. 3단계 · 5~6개월브라우저 확장 — 결제 순간 감지해 자동 등록 제안

기술 구성: Cloudflare Pages(웹앱) · Workers(서버) · Workers AI(기한 추출) · D1(데이터) · 예약 실행(알림) — 초기 비용 거의 없음
